4-Way Traffic Light Simulation

An Arduino-based 4-way traffic light simulation designed and tested using Proteus. The project demonstrates how traffic signals can be programmed to control vehicle movement at a four-road intersection.

Features
- Four-way traffic light control
- Arduino-based signal sequencing
- Red, yellow, and green light control
- Timed traffic signal transitions
- Proteus simulation for circuit testing
- Simple and easy-to-understand Arduino code

Requirements
- Arduino
- Proteus Design Suite
- LEDs for traffic signals
- Resistors
- Connecting wires
- Arduino code

How It Works
The Arduino controls the traffic lights for four directions. Each direction receives a green signal for a defined period, followed by a yellow transition before the next direction is given permission to proceed.

The circuit can be simulated in Proteus before being implemented on physical hardware.

Simulation
Open the Proteus project file and load the Arduino program. Start the simulation to observe the four traffic signals operating sequentially.
